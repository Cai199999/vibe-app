# 阶段十：前端模式入口与极简界面（2026-11-02）

## 目标

在不修改后端任何逻辑的前提下，为 `canvas-ui` 增加模式选择入口，并对主界面做减法：

- 入口页二选一：加载本地 Vite 项目（源码模式）或直接使用截图（仅视觉模式）；
- 截图模式跳过 3 秒 SDK 握手，直接进入黄色「视觉」状态；
- 顶部提供退出 / 切换模式按钮，可返回入口页；
- 主画布和右侧工作台移除长说明、重复提示与大段文字警告。

## 状态机

`App` 新增 `workspace: 'landing' | 'source' | 'visual'`：

| 入口 | workspace | project | bridge.status | 默认模式 |
|---|---|---|---|---|
| 加载本地项目 | `source` | 真实 `LocalProject` | 3 秒探测，成功 `connected`，失败 `visual` | 旁注 |
| 使用截图 | `visual` | `null`（生成时使用固定回环元信息） | 强制 `visual`，不启动握手计时器 | 圈画 |
| 退出 / 切换 | `landing` | `null` | `idle` | 旁注 |

- `useIframeBridge(previewOrigin, projectKey, forceVisual)` 新增第三参数；首帧即返回 `visual`，避免状态闪烁。
- 截图工作区的 L3 请求使用固定 `http://127.0.0.1:5173` 与名称「截图工作区」，仅用于满足请求 DTO，不发起 iframe 请求。
- 仅视觉模式过滤旁注 / 拖拽工具；若源码握手超时降级，当前模式按圈画生效。

## UI 减法

- 删除原画布内 `ProjectLauncher`，由独立 `LandingPage` 取代。
- 顶部：品牌副标题、模式长说明、底部快捷键浮条、视觉错误横幅全部移除；状态压缩为绿点「源码」/ 黄点「视觉」/「探测中」。
- 远程加载安全警告改为 ⚠️ 图标 + `title`；视觉隐私提示改为 🔒 图标 + `title`，标注弹窗使用「截图不脱敏」小标签。
- 右侧工作台只保留标签页（标注 / Prompt）、标注列表、生成按钮与结果区；删除标题、LOCAL 徽章、API 地址脚注和介绍文案。
- Prompt 空态、加载态、错误态改为短文案；删除请求 ID / 时间脚注。
- Toast：仅保留截图成功、错误与少量状态提示；加载项目、添加标注、生成成功不再弹 Toast。
- 新增 `home`、`lock` 图标；预览标题栏状态改为纯色点，切换按钮统一为「切换」。

## 用户操作路径

1. 打开画布 → 入口页；
2. 选择「加载本地项目」→ 输入 Vite 地址 → 进入画布 → 等待 3 秒握手；
   或选择「使用截图」→ 直接进入视觉工作区；
3. 视觉工作区按提示上传或 `Ctrl/Cmd + V` 粘贴截图；
4. 源码模式：旁注 / 圈画 / 拖拽；视觉模式：圈画；
5. 右侧点击「生成指令」→ 查看 Prompt → 复制；
6. 顶部主页图标或预览标题栏「切换」返回入口页。

## 已知边界

- 视觉模式的截图仍只存在浏览器内存，退出工作区即清空；
- 迁移后的入口页保留原有地址校验、远程开关读取、危险端口拦截与 lastProjectUrl 预填；
- 截图工作区不渲染 iframe，也不具备交互浏览真实页面的能力。
