## 建议体验路径

1. 右侧空状态点击 **「载入 3 条示例标注」**，直接看到旁注、圈画、拖拽三种标注。
2. 也可以用顶部模式栏手动体验：
   - **交互 V**：预览可点击，不产生标注。
   - **抓手 H** / 空格 + 拖动 / 滚轮：平移画布。
   - **旁注 N**：点击页面元素 → 输入修改意图 → `⌘/Ctrl + Enter` 保存。
   - **圈画 P**：按住拖动画圈 → 松手 → 补充意图 → 保存。
   - **拖拽 D**：拖拽元素到目标位置 → 松手 → 补充意图 → 保存（只记录位移，不改真实 DOM）。
3. 右侧清单可以点选定位、单条删除、撤销（`⌘/Ctrl + Z`）、清空。
4. 点击 **「保存并提交」**，观察 4 步本地 Agent 流程，查看生成的 **Prompt / 结构化 JSON**。
5. 点击 **「模拟执行并刷新」**，看预览刷新、标注变为「已应用」、版本号从 `v1` 变为 `v2`。

## 这个原型实现了什么

- 无限画布：平移、缩放、适应画布、100% 复位。
- 同源 iframe 预览：`srcdoc` 加载演示页面，父页面可读取 DOM。
- 源码绑定：演示元素带 `data-source` / `data-component`，标注按「源码 + 实例序号」绑定。
- 三种意图采集：旁注、自由圈画（包围盒 + 覆盖元素）、拖拽位移（ghost + 箭头）。
- 标注清单：编号、类型、源码路径、意图、状态、删除、撤销、清空。
- 提交后生成结构化 JSON 与给外部 AI 工具的 Prompt，可复制。
- 模拟刷新：按目标组件做固定演示变更，重新锚定标注并更新状态。

## 明确模拟的部分

- 演示页面是 **纯 HTML 的 mock Dashboard**，不是真实 React 项目；最终架构使用用户自有 Vite React 项目 + 跨域 iframe + SDK。
- Agent 的 4 步流程和第 3 步 DeepSeek 都是 **定时模拟**，没有网络请求、没有 API Key。
- **「模拟执行并刷新」不会执行生成的 Prompt**，只做固定演示变更：按钮文案/主色、指标卡间距/圆角/描边、图表描边、表格高亮。
- 按 Q1 / Q2 的最终边界：系统只输出 Markdown Prompt，由用户复制到 Cursor 等外部工具执行；系统不修改代码、不生成 Diff、不控制刷新。
- 演示页中的 `data-source` 是手工标记；最终方案由 **Vite 插件**在开发环境注入，见架构设计。

## 已知限制

- 圈画的覆盖元素使用包围盒相交判断，嵌套的父容器可能被一并选中；正式实现需要更精细的命中策略。
- 标注重定位依赖 `data-source` + 实例序号 + 世界坐标；元素消失后会标记「元素失效」，但不会自动迁移到新元素。
- 没有持久化、多项目、登录、协作、截图理解、触摸双指缩放。
- 没有真实调用 DeepSeek，也没有真实执行代码修改。
